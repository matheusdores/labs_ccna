# Laboratórios de redes - Matheus Dores

Estudos práticos de redes na preparação para o Cisco CCNA.

## Projeto integrado em preparação
[CCNA Enterprise Lab: matriz e filial](docs/ccna-enterprise-lab.md)

Planejamento de uma rede com VLSM, VLANs, LACP, STP, OSPFv2, IPv6, DHCP, NAT/PAT, ACLs e troubleshooting. O guia inclui topologia, mapa de portas, lista de imagens e testes de aceitação. **Ainda não executado/validado.**
